THE BIG PICTURE

A place to think things through.

Add blocks for components, services, data, and decisions. Draw an arrow from the caller to the receiver. Give the arrow a label such as POST /orders, publishes event, or yes.

Connect: drag from a block’s dot to another block, or choose Connect and click a source followed by a destination. Ports on all four sides let you choose the route. Select an arrow to edit its label and direction.

Navigate: drag empty space to pan; scroll or pinch to zoom. On touch screens, tap + to open the block library. Choose Connect to link blocks with two taps.

Browser storage keeps your latest diagram on this device when available. Export JSON for reliable backups, or save a portable HTML copy to carry the editor and diagram together. Opening another diagram replaces the current canvas; Undo restores it.

Use ⌘ instead of Ctrl on a Mac. This tool plans architecture and algorithms; it does not run the software shown in your graph.
